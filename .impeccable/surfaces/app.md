# Surface: Salvage app (all screens)

Mode: Operate. Native macOS app, light + dark from the system setting.

## Direction contract

THESIS: A Swiss railway timetable for deleted files: exact, calm, aligned. Every number sits on the grid and every file shows its departure time. It refuses the generic "dark dashboard with blue pills and status badges".

OWN-WORLD: System SF Pro with tabular figures everywhere numbers live. Neutral ground tinted cool graphite (dark) or paper-white (light), hairline rules instead of boxes and pills. One accent: Salvage blue for selection and the primary action. One signal: a warm signal orange that appears only for files gone in 7 days or less. Status speaks in small dot + text, never in filled pills.

STORY: The user sees every file is found, sees which ones leave soonest, picks with confidence, restores, and sees each one come back.

FIRST VIEWPORT: Overview: large quiet total ("2,929 files · 15.56 GB") set like a timetable heading, a single line of state, then the folder table with right-aligned tabular numbers and a thin size bar per folder. Primary action "Browse and restore" top right.

FORM: Swiss timetable / station clock, position 7 of the grounded list. seed: 588c2f1cb1a6fd36

SIGNATURE: the "gone in" clock: a 12 px ring per file that empties with the days left (30 → 0), orange at 7 days or less. Restore progress uses the same clock language.
